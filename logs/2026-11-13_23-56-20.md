# Codebase Modification Log — SkyFlip UI for the Backend-Only Features (issue #7)

**Timestamp**: 2026-11-13 23:56:20
**Author**: Claude Code (AI Assistant) & Wut
**Branch**: skyflip-ui-features (built on supabase-real-spherex)
**Action**: Added to the SkyFlip viewer every feature the backend already served but the UI did not show: spectrum, difference image, shift-and-add, narrow-band filters and indices, Gaia + AllWISE overlay with the brown-dwarf flag, and candidate flagging, voting and MPC export. Frontend only; no backend or database changes.

---

## 1. Summary of Changes
- **Spectrum** (`/api/spectrum`): new section under the player, "The light here, split into 102 colours". It is fetched only when the visitor presses "Measure the light here", because the backend must first download every picture of the spot. Shows the 202 download progress, then a line chart (brightness against wavelength, detector bands marked along the bottom), a hover and arrow-key readout, and a table of the same numbers.
- **Difference image** (`difference_image_url`): a "What changed" view in the player with a red/blue key in plain words.
- **Shift-and-add** (`/api/shift-and-add`): a "Combined" view with two drift sliders (−8 to 8 pixels per visit) and a "Combine with this drift" button.
- **Filters and indices**: a "More kinds of light…" list next to the band buttons, filled from `/api/bands` (colour picture, molecule filters, standard filters, comparisons). The choice is kept in the address bar (`?band=filter_ch4_deep`). Slow first loads show the download progress with a "15 minutes or more" note. "What changed" and "Combined" are switched off for the colour picture, which the backend does not support there.
- **Catalogue overlay** (`/api/catalog-overlay`): a "Known stars" switch. Circles = Gaia, squares = AllWISE, diamonds = possible brown dwarfs. Clicking a mark shows its name, brightness and motion; possible brown dwarfs also get buttons so they can be reached by keyboard. It is only looked up when switched on (about 30 s).
- **Flags** (`/api/candidates…`): a "Flagged in this picture" panel. "Flag something here" puts an orange ring on the centre; clicking the picture moves it; a short form (what, how sure, notes, optional nickname) saves it. Existing flags are numbered on the picture and listed with an "I see it too" vote button. With no spot chosen, the panel lists every flag with a link to its spot. A link downloads the MPC report. No delete button (there is no login, issue #6).
- **Loading fix found on the way**: switching to a band that was still downloading used to keep the old band's pictures on screen with no progress. The shared loading hook now clears them as soon as the backend reports a download.
- **Phones**: the light label on the picture moves under the date label on narrow screens so long filter names do not cover it.

## 4. Known Limits
- Voting has no limit per person (issue #5) and flags have no owner (issue #6); the UI does not pretend otherwise.
- The WISE 0855 spectrum has one tall spike near 1.1 µm (about 1.0 MJy/sr against 0.02–0.1 elsewhere). The UI shows the backend's numbers as they are; worth a look in `build_spectrum`.
- The filter descriptions come straight from the backend and are written for astronomers, not the public.
- The drift sliders do not say which way is positive; the direction convention of `perform_shift_and_add` was not verified.
