# Left/Right Arrow Key Navigation for Epoch Frames
**Timestamp**: 2026-11-14 16:30:35 +07:00
**Branch**: `restoring-old-features`

## Summary
Added `ArrowLeft` and `ArrowRight` keyboard shortcuts to step backward and forward through observation epochs in the Flipbook player.

## Changes Made
- **[`frontend/src/components/FlipPlayer.jsx`](file:///Users/Alpha/Desktop/MeowzaNasaSpaceApp2026/frontend/src/components/FlipPlayer.jsx)**:
  - Updated `useFlipbook`'s `show` helper (wrapped in `useCallback`) to accept either a target index or a functional updater `(prevFrame) => nextFrame` so keyboard navigation always steps from the latest frame and wraps modulo `count` while pausing playback.
  - Extended the `FlipPlayer` `keydown` listener to handle unmodified `ArrowLeft` and `ArrowRight` keys outside form inputs (`input, textarea, select, [contenteditable]`), preventing default scroll and stepping between epochs.
  - Added `title="Previous picture (←)"` and `title="Next picture (→)"` to the previous/next frame buttons.
