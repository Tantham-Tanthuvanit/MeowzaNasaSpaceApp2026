# Engineering Log: 2026-11-13 15:39:13

## Scope of Work
- **Feature**: Anti-Spam & Voter Deduplication for Community Discovery Corroboration
- **Context**: Prevent rapid click spamming and vote inflation on flagged candidates in the citizen science discovery database.
- **Affected Components**:
  - `backend/database.py`
  - `backend/main.py`
  - `backend/flask_app.py`
  - `backend/test_suite.py`
  - `frontend/src/services/api.js`
  - `frontend/src/components/FlaggedDiscoveries.jsx`
  - `frontend/src/App.jsx`

## Modifications

1. **Backend Database Deduplication & Toggle Architecture (`database.py`)**:
   - Added `voter_id` column to `community_votes` table with safe automatic migration.
   - Enforced `PRAGMA foreign_keys = ON;` on all database connections to prevent orphaned rows when candidates are removed.
   - In `vote_candidate()`:
     - Detects prior votes from the caller using `(candidate_id, voter_id)` or `(candidate_id, voter_callsign)`.
     - Blocks duplicate votes when `vote_type == "corroborate"`, returning `{ "already_voted": True }` without inflating `upvotes`.
     - Supports `vote_type in ["unvote", "remove"]`, allowing voters to revoke their corroboration cleanly (decrements `upvotes = MAX(0, upvotes - 1)`).
   - In `add_candidate()` and `delete_candidate()`: Explicitly prune any associated votes to guarantee referential integrity.
   - Cleaned database upvote counts back to benchmark baselines (14 for Sedna, 28 for WISE 0855, 9 for Luhman 16).

2. **Dual-Backend REST Endpoints Parity (`main.py` & `flask_app.py`)**:
   - Updated `VotePayload` model and Flask route to accept `voter_id` and pass it to `database.vote_candidate()`.

3. **Frontend Anti-Spam & Corroborate Toggle (`FlaggedDiscoveries.jsx`, `api.js`, `App.jsx`)**:
   - Created persistent unique voter identifier (`spherex_client_voter_id`) stored in `localStorage`.
   - Tracked corroborated candidate IDs in `localStorage` under `spherex_user_voted_candidates`.
   - Added in-flight debounce lock (`isVotingCandidateId`) to completely ignore rapid spam clicks during network transmission.
   - Visual Toggle States:
     - Uncorroborated: Cyan button `👍 Corroborate (N)`.
     - Corroborated: Emerald green badge `✓ Corroborated (N)` with subtitle explaining clicking again will remove the vote.
   - Made `handleVoteCandidate` in `App.jsx` return updated candidate object for immediate UI state synchronization.

4. **Testing & Verification**:
   - Added anti-spam unit tests to `backend/test_suite.py`:
     - Verified duplicate vote submission by same voter does not increment `upvotes`.
     - Verified `unvote` payload decrements count back to base level.
   - FastAPI test suite (`test_suite.py`): 23/23 tests passed.
   - Flask test suite (`test_flask.py`): 9/9 tests passed.
   - Total 32 tests passing.
   - Frontend production build (`npm run build`): Compiled in 916ms.
