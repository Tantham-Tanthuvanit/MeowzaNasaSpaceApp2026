## 1. Summary of Changes

- **`frontend/src/core/ruler.js`**:
  - Implemented `pixelToSky(x, y, ra0, dec0, fov)`: Inverts image canvas pixels (0-256) back into celestial coordinates (RA, Dec).
  - Implemented `calculateMeasurement(p1, p2, ra0, dec0, fov)`:
    - Calculates pixel distance and angular separation in arcseconds ($″$), arcminutes ($′$), and milliarcseconds ($\text{mas}$).
    - Calculates IAU astronomical Position Angle ($0^\circ = \text{North}$, $90^\circ = \text{East}$, $180^\circ = \text{South}$, $270^\circ = \text{West}$) and compass direction.
    - Computes endpoint celestial coordinates for Point A and Point B and coordinate offsets ($\Delta\text{RA}$, $\Delta\text{Dec}$).
  - Implemented `calculateProperMotion(distanceArcsec, deltaDays)`: Calculates apparent proper motion speed in arcsec/year and mas/year.
  - Implemented `getScaleBar(fov)`: Computes clean round scale lengths (e.g. $10''$, $30''$, $1'$, $2'$, $5'$) calibrated to the active field of view.
- **`frontend/src/core/ruler.test.js`**:
  - Unit tests covering coordinate inversion roundtrip, angular separation, position angle orientation in all four cardinal quadrants, epoch proper motion speed, and dynamic scale bar width bounds.
- **`frontend/src/components/RulerOverlay.jsx`**:
  - Renders the dynamic astronomical corner scale bar in the bottom-left corner with high-contrast text and end ticks.
  - Renders Point A and Point B glowing reticles with crosshairs and labels, connecting measurement line with perpendicular end ticks, and midpoint distance badge.
- **`frontend/src/components/RulerPanel.jsx`**:
  - Measurement card displaying primary angular distance, detector pixels, Position Angle, coordinate endpoints, offsets, and multi-epoch proper motion velocity calculator across survey visits.
- **`frontend/src/components/FlipPlayer.jsx` & `frontend/src/components/SplitPlayer.jsx`**:
  - Added pointer move/leave and keyboard shortcut (`M`/`m`) support.
- **`frontend/src/pages/Viewer.jsx`**:
  - Integrated ruler state, pointer handlers, SVG overlay, and right sidebar toggle button (`Ruler & measurement`, shortcut `M`).
- **`frontend/src/components/SettingsModal.jsx` & `README.md`**:
  - Documented `M / m` shortcut under Keyboard & Controls.
  - Updated README feature list and architecture tree.
