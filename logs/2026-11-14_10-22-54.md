# Codebase Modification Log — Pages Fit the Screen on Laptops and Desktops

**Timestamp**: 2026-11-14 10:22:54
**Author**: Claude Code (AI Assistant) & Wut
**Branch**: skyflip-ui-features
**Action**: On large screens (`lg`, 1024px and up) the app is now exactly the height of the window, so the sky map and the sky viewer no longer scroll up and down as a whole page.

---

## 1. Summary of Changes
- **App shell**: on `lg`+ the app is `h-dvh` with the page in between header and footer taking the height that is left. The data credits footer is now one line ("Data credits: NASA SPHEREx (IRSA), Gaia DR3, AllWISE") that opens to the full credit text (a `<details>`, on all screen sizes). The full wording is unchanged.
- **Sky map**: the map takes the height that is left and keeps its shape, using a size container (`min(100cqw, 100cqh*1640/780)`). The heading shrinks a little on short windows so it stays on one line. The repeated "Drag to turn · Scroll…" hint under the map is hidden on `lg`+ (the same instructions are in the intro line, and still shown on phones).
- **Sky map messages**: the loading/error messages and the "Real picture of the sky" caption sat between the two corner panels with fixed padding, which crushed them when the map was narrower than ~1080px. They now go there only when the map is that wide (container query); otherwise the messages sit at the top like on phones and the caption is hidden.
- **Sky viewer**: on `xl`+ each of the three columns scrolls on its own inside the window; on `lg` the page area scrolls inside the window. The picture's size follows the window height (`.player-w`, `min(700px, 100dvh - 300px)`) so the picture, play controls and picture buttons are visible together. The slider's minimum width is 80px instead of 120px so the play controls stay on one row in a narrow column.
- Phones are unchanged apart from the one-line credits footer: they still scroll normally, since the flipbook and its controls cannot fit on a phone screen.
