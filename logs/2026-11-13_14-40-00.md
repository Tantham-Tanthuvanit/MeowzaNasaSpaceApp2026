# Codebase Modification Log — SkyFlip Frontend Replaces the Temporary Frontend

**Timestamp**: 2026-11-13 14:40:00
**Author**: Claude Code (AI Assistant) & Wut
**Branch**: skyflip-ui
**Action**: Replaced the temporary dark-theme frontend with the SkyFlip UI (Home sky map + Sky viewer) from Wut's design, wired to the existing backend. No backend code changed.

---

## 1. Summary of Changes
- **New look and two pages**: light SkyFlip UI (Inter, Space Grotesk, JetBrains Mono, orange accent `#FF8A3D`) with a Home page (`#/`) and a Sky viewer page (`#/viewer`). Uses `HashRouter` because the backend serves the built site only at `/`.
- **Home page**: drag/zoom all-sky map (Mollweide-style), glowing ring markers with name chips for each project, a details card (EQ-J2000 position, bands, created date, Open in Sky viewer / Edit / Delete with in-card confirmation), a pin + coordinates card for clicking an empty spot, a shared create/edit dialog, and a "How do sky positions work?" explainer.
- **Sky viewer page**: RA/Dec form, target list loaded from `/api/presets` (all 9), flipbook player showing the real `/api/sky-cutout` frames with their dates, play/pause, step, scrubber, speed, one thumbnail per epoch, band tabs (All bands + Band 1–6, mapped to `band_group=stacked|array_n`), project info and "Save as project".
- **Projects** are stored in browser `localStorage` (key `skyflip_projects`) behind `src/core/projects.js`, seeded with the five challenge stars. Moving to backend storage later only needs that file changed.
- **Shared logic with tests**: map projection and RA/Dec parsing/formatting in `src/core/sky.js` (14 Vitest tests). Star text, bands and colours in one file, `src/core/targets.js`.
- **API layer**: the silent mock-data fallback was removed. If the backend is down the player shows a clear message and a "Try again" button.
- **Responsive**: no fixed 1920×1080 frame. Viewer columns stack on narrow screens; on phones the map cards and controls sit under the map.
- **Removed from this branch** (still on `master`): the temporary dashboard components and their features (difference image, split view, shift-and-add, catalog overlay, candidate flagging, spectrum chart), `mockData.js`, `astrometry.js`, and the Tailwind CDN script in `index.html`.
- **Note**: the shared-logic folder is named `src/core` because the root `.gitignore` ignores any folder named `lib/`.
- **Note**: `frontend/FIGMA_PREP_GUIDE.md` now describes the old components and is out of date. It was left unchanged.
