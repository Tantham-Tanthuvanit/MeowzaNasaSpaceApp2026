## 1. Summary of Changes
- **`setup.sh` & `start.sh`**:
  - Added `find_venv_python()` to resolve both Windows (`backend/venv/Scripts/python.exe`) and Unix (`backend/venv/bin/python`) virtual environment layouts.
  - Updated Python discovery in `setup.sh` to check Python 3.14/3.13+, iterate through all matching executables in `PATH` (`which -a`), include `$LOCALAPPDATA/Python/bin`, and fall back to `py -3`, avoiding broken Windows Store `python.exe` alias stubs.
  - Switched backend launch in `start.sh` to `"$VENV_PYTHON" -m uvicorn main:app --host 0.0.0.0 --port 8000` for cross-platform compatibility.
- **`setup.ps1`, `start.ps1`, `setup.bat`, `start.bat`** (new):
  - Native Windows PowerShell and Command Prompt scripts so Windows users can run `.\start.bat` or `.\start.ps1` directly without needing Git Bash.
- **`.gitattributes`** (new):
  - Enforces `*.sh text eol=lf` so Git on Windows does not convert shell scripts to CRLF line endings.
- **`backend/main.py`**:
  - Checked `os.path.isdir(os.path.join(frontend_dist_dir, "assets"))` instead of `os.path.exists(frontend_dist_dir)` before mounting `/assets`, preventing FastAPI from crashing on startup when `frontend/dist/index.html` exists without a built `frontend/dist/assets` directory.
- **`backend/.env.example`**:
  - Fixed variable name typo (`SUAPBASE_URL` -> `SUPABASE_URL`).
- **`README.md` & `CLAUDE.md`**:
  - Documented Windows setup and startup commands alongside Unix commands.
