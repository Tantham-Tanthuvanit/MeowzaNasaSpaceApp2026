## 1. Summary of Changes
- **Holes found and fixed** (migration `harden_public_access`, applied to Meowza):
  1. **The cache could be overwritten** (high). Any signed-in user could replace the 3702 cached pictures, cutout rows, results and image lists for everyone.
     - Now the cache is write-once: no UPDATE on `sky_cutouts`/`sky_results`, `sky_positions` can only update `status`/`error`/`updated_at`, and there is no replace policy on storage.
     - The backend now inserts and ignores duplicates (`upsert(..., ignore_duplicates=True)`, and `_put_file` uploads with `upsert: false`, keeping a file that is already there).
  2. **Vote stuffing** (high). `voter_id` was free text, so one user could vote many times.
     - New check: `voter_id = owner_id::text` (old ownerless votes are kept).
     - With the publishable key, `database._me()` uses the install's signed-in user id instead of the browser's id. The existing unique index then means one vote per user per flag.
  3. **No size limits** (medium). One request could fill the 500 MB database.
     - Check constraints on every text/JSON column, set well above today's largest values (notes ≤ 2000, payload ≤ 1 MB of text, image list ≤ 2 MB of text, etc.).
  4. **Row floods and fake dates** (medium).
     - Trigger `private.stamp_and_cap()` sets `created_at` to server time and allows at most 300 new flags and 300 new projects per user a day (raised from 50 by `20261115224800_raise_daily_caps.sql`).
     - It is a trigger-only function in a schema the API doesn't expose.
- **Already fine**:
  - `.npy` cutouts load with `allow_pickle=False`.
  - Cutout downloads always go to `https://irsa.ipac.caltech.edu/` + the stored path.
  - Image URLs are signed from bucket paths.
  - React escapes all text; there are no `dangerouslySetInnerHTML` sinks.
  - There are no public functions or views.
- **Settings**: `backend/.env.example` is renamed to `backend/public.env` and read directly, so there is no copy step. The optional, git-ignored `backend/.env` still overrides it (owners put the secret key there).
- **Behaviour change**:
  - With the public key, one install = one voter (two browsers on one computer share one vote).
  - People who voted before today, under their browser id, can vote once more under their user id.
  - The live round-trip test needs an owner's secret key (noted in `CLAUDE.md`).
