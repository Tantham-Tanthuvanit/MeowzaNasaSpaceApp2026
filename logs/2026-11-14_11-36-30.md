## 1. Summary of Changes

- **WebGL Non-Power-of-Two (NPOT) Texture Wrap Fix** (`frontend/src/components/SkyCanvas.jsx`):
  - Changed `gl.TEXTURE_WRAP_S` from `gl.REPEAT` to `gl.CLAMP_TO_EDGE`. In the WebGL 1.0 specification, using `REPEAT` on NPOT textures (such as `skymap_equatorial.webp` at 2400×1200) marks the texture as incomplete and fails rendering (sampling returns solid black).
  - Updated the fragment shader to calculate equirectangular texture coordinates using `fract(angle / (2.0 * PI))` and `clamp(0.5 - (dec / PI), 0.0, 1.0)`, ensuring seamless 360-degree horizontal wrapping in shader code.
  - Added support for `webgl2` context detection with fallbacks to `webgl` and `experimental-webgl`.
  - Removed `crossOrigin = 'anonymous'` on same-origin local assets and added an `onerror` fallback from `.webp` to `.jpg`.
  - Unified the rendering callback via `renderRef` and `viewRef` so view updates and image load callbacks never use stale closures or duplicate render logic.
  - Added clean resource deletion on component unmount (textures, buffers, shaders, program).

- **Backend Dist Asset Serving & SPA Fallback** (`backend/main.py`):
  - Added route `/{filename:path}` to serve files directly from `frontend/dist` (e.g. `skymap_equatorial.webp`), while rejecting `/api/` paths so API 404s are preserved.
