## 1. Objective & Architectural Overview
To win and stand out in the NASA Space Apps Challenge 2026 Global Round, we built an embedded, zero-configuration backend database engine (`backend/database.py`) and integrated it into the SPHEREx Sky Viewer. This transitions the platform from a local browser viewer into an authentic multi-user Citizen Science Community Verification Platform inspired by NASA Zooniverse / Backyard Worlds: Planet 9.

### Key Capabilities Built:
1. **Embedded SQLite Database (`backend/database.py`)**:
   - Zero-dependency, portable SQLite database stored at `backend/data/discoveries.db` (git-ignored, auto-created and seeded upon application launch).
   - Schema with two relational tables: `candidates` (astrometric coordinates, pixels, classification, confidence, notes, observer callsign, upvotes) and `community_votes` (corroborations, peer-review comments, timestamps).
   - Automatic seeding of 3 realistic NASA Space Apps benchmark discoveries:
     - 90377 Sedna (Planet X orbital drift analog across 4 SPHEREx epochs).
     - WISE 0855 (Sub-stellar brown dwarf dipole optical dropout).
     - Luhman 16 (Binary companion separation with 3.3µm methane absorption).
2. **REST API Endpoints (Dual Backend Parity for FastAPI & Flask)**:
   - `GET /api/candidates`: Query community discoveries with optional category filtering and spatial cone searches (`ra`, `dec`, `radius_deg`).
   - `POST /api/candidates`: Create and persist candidate detections with celestial coordinates and observer callsign.
   - `GET /api/candidates/<id>`: Retrieve specific candidate and corroboration vote history.
   - `POST /api/candidates/<id>/vote`: Cast community corroboration votes and scientific peer-review comments.
   - `DELETE /api/candidates/<id>`: Remove a candidate discovery.
   - `GET /api/candidates/export-mpc`: Export all vetted discoveries formatted according to Minor Planet Center (MPC) and NASA IRSA submission standards.
3. **Frontend Full-Stack Integration**:
   - `frontend/src/services/api.js`: Added `fetchCandidatesApi`, `createCandidateApi`, `voteCandidateApi`, `deleteCandidateApi`, `fetchMpcDossierApi`, and normalized candidate data structures.
   - `frontend/src/App.jsx`: Synchronized React state with the SQLite database on startup and upon flagging, voting, or deleting.
   - `frontend/src/components/FlaggedDiscoveries.jsx`:
     - Added Citizen Scientist observer handle/callsign input.
     - Added interactive community `👍 Corroborate ({upvotes})` button for peer reviews.
     - Added direct 1-click `Export MPC Format` button alongside the NASA verification dossier and JSON exports.
