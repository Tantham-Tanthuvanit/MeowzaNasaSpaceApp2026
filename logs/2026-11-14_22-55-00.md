## 1. Summary of Changes
- **`backend/database.py`**:
  - Added `_pack_epoch_owner()` / `_unpack_owner()` helpers to store the creator's `voter_id` in `candidates.epoch_label` using a private `__owner__:<voter_id>\n<epoch>` envelope, stripping it before returning any API response so `voter_id` is never leaked.
  - Updated `add_candidate()` to record creator `voter_id` and return `user_owned`.
  - Updated `get_candidates()`, `get_candidate_by_id()`, and `vote_candidate()` to compute `user_owned` (`bool(voter_id and owner_id and owner_id == voter_id)`).
  - Updated `delete_candidate(candidate_id, voter_id)` to verify `voter_id == owner_id`, returning `'deleted'`, `'not_found'`, or `'forbidden'`.
- **`backend/main.py`**:
  - Extended `CandidatePayload` with optional `voter_id` (1–100 chars).
  - Updated `GET /api/candidates/{candidate_id}` with optional `voter_id` query parameter to return `user_owned`.
  - Updated `DELETE /api/candidates/{candidate_id}` with `voter_id` query parameter, returning HTTP `403` when missing/non-owner, `404` when absent, or `200` on owner deletion.
- **`frontend/src/services/api.js` & `frontend/src/components/Flags.jsx`**:
  - Updated `flagCandidate()` to attach `voter_id: voterId()` when submitting a new flag, and exported `deleteCandidate(id)`.
  - Displayed a `"Your flag"` badge and **"Delete"** button with inline confirmation (`"Delete your flag?"` → `"Cancel"` / `"Delete flag"`) exclusively when `c.user_owned` is true.
- **`backend/test_suite.py`, `docs/API.md`, `README.md`**:
  - Added `test_delete_candidate_requires_owner` to `TestApiMapping` and updated `TestLive.test_candidate_and_project_round_trip` to verify `user_owned` and owner-only `DELETE` enforcement (`403` vs `200`) live against Supabase.
  - Updated `docs/API.md` and `README.md`.
