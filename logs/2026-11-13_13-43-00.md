## 1. Summary of Changes
Implemented the primary citizen science objective modeled directly after **Zooniverse: Backyard Worlds: Planet 9** and **WiseView**:
- **Interactive Click-to-Flag Candidate Mode**:
  - Added targeting mode toggle (`isFlaggingActive`) in [frontend/src/components/SkyViewer.jsx](file:///Users/Alpha/MeowzaNasaSpaceApp2026/frontend/src/components/SkyViewer.jsx).

- **Astrometric Coordinate Transformation Engine**:
  - Created [frontend/src/services/astrometry.js](file:///Users/Alpha/MeowzaNasaSpaceApp2026/frontend/src/services/astrometry.js) implementing `pixelToRaDec()`, `raDegToHms()`, and `decDegToDms()`.
  - Added corresponding backend helper `pixel_to_radec()` in [backend/coordinates.py](file:///Users/Alpha/MeowzaNasaSpaceApp2026/backend/coordinates.py).
  - Added REST endpoint `/api/pixel-to-radec` in both [backend/main.py](file:///Users/Alpha/MeowzaNasaSpaceApp2026/backend/main.py) and [backend/flask_app.py](file:///Users/Alpha/MeowzaNasaSpaceApp2026/backend/flask_app.py).
- **Flag Candidate Confirmation Modal**:
  - Implemented `FlagCandidateModal` in [frontend/src/components/FlaggedDiscoveries.jsx](file:///Users/Alpha/MeowzaNasaSpaceApp2026/frontend/src/components/FlaggedDiscoveries.jsx).
  - Displays live astrometric telemetry ($RA/Dec$ in sexagesimal and decimal degrees, canvas pixel coordinates, and observation epoch).
  - User can classify candidate:
    - 🪐 **Planet X / TNO** (Detached Kuiper Belt Object)
    - ⚡ **Brown Dwarf Candidate** (High proper motion dipole)
    - ✨ **Variable Star / Flare** (Photometric variability)
    - ☄️ **Asteroid / Comet** (Fast Solar System mover)
    - ⚠️ **Possible Artifact** (Cosmic ray / diffraction spike)
  - Supports confidence rating (1–5 stars) and user observer notes.
- **Interactive Canvas Pins & Candidate Reticles**:
  - Pins are rendered directly over the canvas with glowing animated rings and numbered badges (`🚩 #1`, `🚩 #2`).
  - Clicking or hovering on any pin reveals candidate metadata with an option to remove the pin.
- **Flagged Discoveries Management Panel & NASA Dossier Exporter**:
  - Implemented `FlaggedDiscoveriesPanel` in [frontend/src/components/FlaggedDiscoveries.jsx](file:///Users/Alpha/MeowzaNasaSpaceApp2026/frontend/src/components/FlaggedDiscoveries.jsx) rendered in [frontend/src/App.jsx](file:///Users/Alpha/MeowzaNasaSpaceApp2026/frontend/src/App.jsx).
  - Persists flagged discoveries across sessions using browser `localStorage`.
  - **1-Click Export NASA Dossier (.txt)**: Generates a formatted scientific verification dossier adhering to NASA / IRSA / Minor Planet Center (MPC) citizen science discovery standards.
  - **1-Click Export JSON**: Exports machine-readable candidate arrays with all astrometric parameters.
