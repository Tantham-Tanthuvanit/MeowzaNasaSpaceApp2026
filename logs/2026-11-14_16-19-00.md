# Multi-FOV Cache Reuse & WISE 0855 All-FOV Warmup
**Timestamp**: 2026-11-14 16:19:00 +07:00
**Branch**: `restoring-old-features`

## Summary
Added center-cropping cutout reuse from larger cached FOVs at the same celestial coordinate and cross-FOV spectrum sharing in `backend/data_loader.py`, and pre-warmed WISE 0855 across FOV presets (`3′`, `5′`, `8′`, `12′`, `15′`).

## Changes Made
- **[`backend/data_loader.py`](file:///Users/Alpha/Desktop/MeowzaNasaSpaceApp2026/backend/data_loader.py)**:
  - Added `crop_to_fov(arr, fov_arcmin)` to extract the exact central `n × n` SPHEREx tangent grid when a cutout was downloaded for a larger FOV at the same `(RA, Dec)`.
  - Added `_siblings(ra_deg, dec_deg)` so new FOV requests at an already-indexed coordinate reuse the cached IRSA image list without an extra IRSA TAP round-trip, and `_require` falls back to any larger-FOV sibling's cached `.npy` cutouts before queueing IRSA downloads.
  - Updated `get_spectrum` to reuse any existing cached 102-channel spectrum at the same `(RA, Dec)` regardless of `fov_arcmin`, since the spectrum only measures the center pixel.
