## Modifications

1. **Removed FOV Slider (`SearchBar.jsx`, `App.jsx`)**:
   - Removed the FOV range slider from `SearchBar.jsx` to clean up the query toolbar.
   - Refactored the form layout into a balanced 3-column grid (`md:col-span-4` for RA, `md:col-span-4` for Dec, `md:col-span-4` for Query & Share actions).
   - Retained the default 5.0 arcmin FOV fallback across backend query parameters.
   - Removed obsolete `onFovChange` callback from `App.jsx`.

2. **Interactive 2D Drag-to-Pan & Scroll-Zoom Engine (`SkyViewer.jsx`)**:
   - Added `panOffset = { x, y }` state and `isPanning` boolean.
   - Implemented pointer event listeners (`handlePointerDown`, `handlePointerMove`, `handlePointerUp`, touch event equivalents) on the main astronomical canvas container.
   - Cursor feedback: `cursor-grab` by default, `cursor-grabbing` while actively dragging, and `cursor-crosshair` when Candidate Pinning mode is toggled.
   - Implemented drag-detection threshold (`Math.abs(dx) > 3 || Math.abs(dy) > 3`): clicking to pin a candidate or inspect a catalog star still works seamlessly without false triggers during panning.
   - Smooth mouse wheel & trackpad zoom via `handleWheel` (`deltaY`).
   - Unified pan & zoom CSS transform:
     `transform: translate(${panOffset.x}px, ${panOffset.y}px) scale(${zoomLevel})` with `transformOrigin: 'center center'`.
   - Synchronized panning across comparative views: Single View, Side-by-Side Dual View, Trio + Diff Map, and Curtain Wipe slider all shift synchronously.
   - Added Pan tool indicator icon (`Move`) and reset button in the header toolbar (`Reset Pan & Zoom` with visual amber highlight when offset).
   - Real-time offset telemetry badge in bottom-left HUD.
